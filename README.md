# Avtoex — окреме посилання для кожного товару

## Функції
- Клієнт отримує унікальне посилання `/p/<код>` і бачить тільки фото та ціну.
- Головна сторінка не показує каталог товарів.
- Адмін входить через `/login`, додає Allegro URL, встановлює ціну й копіює посилання клієнту.
- Адмін може змінити ціну/фото, приховати чи видалити товар.

## Локальний запуск на Windows
1. Встанови Python 3.10+.
2. Розпакуй ZIP і відкрий PowerShell у папці `avtoex_site`.
3. Виконай:
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:AVTOEX_ADMIN_USER="admin"
$env:AVTOEX_ADMIN_PASSWORD="ВСТАВ_СИЛЬНИЙ_ПАРОЛЬ"
$env:AVTOEX_SECRET="ВСТАВ_ДОВГИЙ_ВИПАДКОВИЙ_СЕКРЕТ"
py app.py
```
4. Відкрий `http://127.0.0.1:5000/login`.
5. Після додавання товару натисни «Копіювати URL» у таблиці та протестуй посилання у приватному вікні.

## Щоб клієнти відкривали посилання через інтернет
Потрібно опублікувати застосунок на Python-хостингу, увімкнути HTTPS, задати змінні середовища на хостингу та налаштувати постійне зберігання `avtoex.db`. Поки застосунок працює локально, посилання доступні лише на твоєму комп'ютері. Після публікації URL матиме справжній домен.

## Важливо
- Автоматичне отримання фото Allegro може блокуватися або бути обмежене правилами сайту. Якщо не працює, використовуй пряме HTTPS-посилання на зображення, яке маєш право використовувати. Для надійного імпорту варто інтегрувати офіційний API Allegro відповідно до його умов.
- Це стартовий MVP, не завершений production-магазин. Перед публікацією додай CSRF-захист, rate limiting, резервні копії та перевір налаштування безпеки.
- Оплата й оформлення замовлення не налаштовані: сторінка показує тільки фото та ціну.
